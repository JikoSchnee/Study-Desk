# Study Desk 知识社区

社区 MVP 位于 `/community`，与本地知识库、分享包和云备份完全分离。开发环境提供沙箱购买；生产环境在没有真实商户适配器时会拒绝结算。

## 本地体验

1. 执行 `npm run dev`，打开 `/community`。
2. 免费知识库可以直接练习。
3. 付费知识库选择限时、永久或作者订阅后执行沙箱购买；开发环境会返回模拟订单和 3 天退款期限。
4. “在桌面端打开”使用 `study-desk://community/practice/:id`。桌面端只接收知识库标识，不从链接继承权益。

## Supabase 部署

1. 先执行 `20260811_study_desk_sync.sql`，再执行 `20260820_community_marketplace.sql`。
2. Web 服务配置 `SUPABASE_URL`、`SUPABASE_ANON_KEY`；支付回调与审核后台另行使用只存在于服务端的 service role key。
3. 客户端不得直接查询 `community_cards`。在线练习只能调用 `get_community_card` RPC；该函数会重新检查账号、知识库权益、作者订阅、期限和撤销状态，并写入访问日志。
4. 支付回调应在可信服务端创建订单与权益。退款成功后设置订单为 `refunded`，同时填写权益的 `revoked_at`，再反向处理作者分账台账。

## 正式支付接入门槛

当前项目故意没有伪造微信或支付宝生产实现。完成企业主体、备案域名、微信支付/支付宝商户认证与分账资质后，将 `/api/community/checkout` 的沙箱分支替换为支付适配器，并新增签名校验、幂等回调、退款和分账任务。

任何在线系统都无法阻止截图、录屏和人工抄录。当前保护边界是：不下载完整内容、逐题授权、动态水印、访问日志、速率与异常行为风控，以及退款后即时撤权。
