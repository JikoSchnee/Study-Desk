# Markdown 卡片导入模板

每个二级标题是一张卡片；标题下每一行会作为一条答案要点导入。请删除本说明后再粘贴到“高级导入：粘贴 Markdown 或 CSV”。

需要导入“开场总述 / 核心要点 / 收束总结”、多个“其他问法”、逐条“回忆提示”或知识库类型与标签时，请下载并使用 CSV 模板：其他问法、核心要点和回忆提示均支持在同一个单元格内换行，系统会按行分别拆分并将答案与提示一一配对。

## RAG 为什么需要重排序？

初步召回关注覆盖率。
重排序关注结果相关性。
把最相关资料放到上下文前面，减少噪声。

## 什么是幂等性？

同一请求执行多次，应产生与执行一次相同的业务结果。
